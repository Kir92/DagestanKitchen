# 🏔️ Дагестанская кухня — Кулинарный сайт

Современное веб-приложение для сохранения и популяризации рецептов дагестанской и кавказской кухни. Аутентичные рецепты, удобный интерфейс и полная система авторизации.

## 🛠 Стек технологий

### **Frontend**
| Технология | Назначение |
|------------|------------|
| **Next.js 15** (App Router) | React-фреймворк, серверные компоненты, роутинг |
| **React 19** | Библиотека пользовательских интерфейсов |
| **TypeScript** | Типизация, улучшенная разработка |
| **TailwindCSS 4** | Утилитарный CSS-фреймворк |
| **HeroUI 2** | Библиотека компонентов (бывший NextUI) |
| **Framer Motion** | Анимации и переходы |
| **next-themes** | Управление темами (светлая/тёмная) |

### **Backend & Database**
| Технология | Назначение |
|------------|------------|
| **NextAuth.js 5** | Аутентификация, OAuth, сессии |
| **Prisma 6** | ORM для работы с базой данных |
| **Prisma Accelerate** | Глобальное кэширование и ускорение запросов |
| **bcryptjs** | Хеширование паролей |

### **Валидация**
| Технология | Назначение |
|------------|------------|
| **Zod** | Валидация схем и форм |

### **DevOps & Tooling**
| Технология | Назначение |
|------------|------------|
| **ESLint 9** | Линтер кода |
| **TypeScript** | Статическая типизация |
| **Turbopack** | Быстрая сборка в режиме разработки |

## 🚀 Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/dagestan-kitchen.git
cd dagestan-kitchen

# 2. Установить зависимости
npm install

# 3. Настроить переменные окружения
cp .env.example .env.local
# Добавить DATABASE_URL, NEXTAUTH_SECRET и др.

# 4. Накатить миграции Prisma
npx prisma migrate dev
npx prisma generate

# 5. Запустить проект
npm run dev
Открыть http://localhost:3000 🎉

📁 Структура проекта
text
